# Smart App Banner مقابل install sheet — شرح عملي مفصّل

## الحل A: Smart App Banner (`apple-itunes-app`) — شريط Apple الأصلي

### ما هو؟
شريط تثبيت **مُعلَن رسمي من Apple** يظهر أعلى صفحة موقعك في Safari على iPhone. يحتوي على أيقونة التطبيق واسمه وزر «Get/Open». ضغطة واحدة → يفتح App Store أو التطبيق مباشرة.

### كيف يعمل؟
تضيف سطراً واحداً في `<head>`:
```html
<meta name="apple-itunes-app" content="app-id=1234567890">
```
حيث `1234567890` هو **App ID الخاص بتطبيقك المنشور في App Store**. Safari يقرأ هذا السطر ويعرض الشريط تلقائياً.

### الشرط الجوهري
> **`app-id` يجب أن يشير إلى تطبيق حقيقي منشور في App Store.**

أي أنك تحتاج:
1. حساب Apple Developer ($99/سنة).
2. بناء تطبيق iOS (حتى لو كان WKWebView يعرض نفس موقعك).
3. رفعه إلى App Store واجتياز مراجعة Apple.
4. الحصول على App ID الذي يعطيه App Store Connect.

### ما يعطيك إياه
| الميزة | القيمة |
|---|---|
| زر تثبيت بضغطة واحدة على iPhone | ✅ نعم — شريط أصلي من نظام Apple |
| يفتح من Safari مباشرة | ✅ نعم |
| مطلوب متجر/دفع | ✅ نعم ($99/سنة) |
| يمكن تخصيص شكله | ❌ لا — شكل Apple ثابت |

### متى تستخدمه؟
عندما تملك تطبيق iOS منشوراً أصلاً (أو تبنيه)، وتريد تحويل زوار موقعك إلى تثبيت بضغطة واحدة.

## الحل B: install sheet + Web Share — حل ويب خالص

### ما هو؟
شريط تثبيت **من تصميمك أنت** (داخل صفحتك) + زر يستدعي `navigator.share()` لفتح لوحة المشاركة النظامية.

### كيف يعمل؟
```js
// 1) شريطك الخاص في الصفحة (HTML/CSS منك)
// 2) زر يستدعي Web Share API
navigator.share({
  title: 'تطبيقنا',
  text: 'ثبّته على الشاشة الرئيسية',
  url: location.href
});
```
المستخدم يضغط الزر → تظهر لوحة المشاركة → يختار «إضافة إلى الشاشة الرئيسية».

### الشرط الجوهري
> **لا يوجد شرط متجر أو دفع — يعمل على أي موقع HTTPS.**

لكن: لا يمكنك التحكم في خيارات لوحة المشاركة (MDN: «available share targets depend on the device»). المستخدم يختار الخيار بنفسه.

### ما يعطيك إياه
| الميزة | القيمة |
|---|---|
| زر تثبيت بضغطة واحدة على iPhone | ❌ لا — خطوتان (زر + اختيار) |
| يفتح من Safari مباشرة | ✅ نعم |
| مطلوب متجر/دفع | ❌ لا — مجاني |
| يمكن تخصيص شكله | ✅ نعم — 100% من تصميمك |

### متى تستخدمه؟
عندما تريد حلاً فورياً مجانياً دون متجر، وتقبل أن المستخدم سيختار «إضافة إلى الشاشة الرئيسية» بنفسه من لوحة المشاركة.

## مقارنة مباشرة

| | Smart App Banner | install sheet + Web Share |
|---|---|---|
| الضغطات للتثبيت | 1 | 2 |
| يحتاج App Store | نعم | لا |
| يحتاج دفع | $99/سنة | مجاني |
| من يرسم الواجهة | Apple | أنت |
| يفتح لوحة مشاركة | لا (يفتح المتجر) | نعم |
| التوفر | iOS Safari فقط | كل متصفح يدعم Web Share |

## أيهما تختار؟
- **عندك تطبيق في App Store أو تستطيع بناءه** → الحل A (أفضل تجربة، ضغطة واحدة).
- **تريد حلاً مجانياً فورياً اليوم** → الحل B (مطبّق في `cranpose-pwa/demo/`).

## ملاحظة صادقة
الفرق الحقيقي ليس في الكود بل في **من يملك «زر التثبيت النهائي»**:
- الحل A: Apple يملكه داخل شريطه الأصلي → ضغطة واحدة.
- الحل B: النظام يملكه داخل لوحة المشاركة → المستخدم يختاره.

لا يوجد حل ثالث ويب يجمع الاثنين (ضغطة واحدة + بدون متجر) — هذه قاعدة Apple وليست قصوراً في مكتبتنا.
